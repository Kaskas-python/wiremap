# wiremap v1 — design and plan

Design approved section by section on 2026-09-14 (brainstorming skill). Open-source,
MIT, public repo `Kaskas-python/wiremap`, PyPI name `wiremap` (free as of 2026-09-14;
`ctxpack` was taken). Origin: the codebase-context debate in
`~/Documents/claude_flow_notes/codebase-context/` — no existing tool resolves the edges
frameworks register at runtime, every index goes stale in worktrees, and MCP tools are
unreachable by the flow's tiered agents. wiremap is a stateless CLI with a content cache.

## Design

### What
A CLI (`uv tool install wiremap`) run from any git checkout, main tree or worktree. Parses
Python and TypeScript with tree-sitter into an in-memory graph on every call: symbols,
containment, imports, calls — plus **framework edges** from a declarative pattern table
(FastAPI `Depends` and route decorators, LangGraph `add_node`/`add_edge`/
`add_conditional_edges`, SQLAlchemy `relationship`, Celery tasks and `.delay`/
`.apply_async`). Every edge carries a confidence: EXTRACTED (literal reference) or
INFERRED (name match). Only a per-file parse cache persists, keyed by content hash under
`~/.cache/wiremap/<repo-sha1>/`. No build step, no server, no file in the repo.

### How (four stages, one process)
1. Discover: `git ls-files` + untracked (`git ls-files --others --exclude-standard`),
   keep `.py .ts .tsx`, skip files > 1 MB.
2. Parse+cache: sha1(content) → cache hit loads symbols + raw edges; miss parses with
   tree-sitter queries (`queries/python.scm`, `queries/typescript.scm`) and writes the
   entry atomically (temp + rename). Entry carries `schema` version; mismatch = miss.
3. Resolve: raw call targets → same module (EXTRACTED) → explicit import (EXTRACTED) →
   unique repo-wide name (INFERRED) → ambiguous: no edge, recorded as unresolved with
   candidate count. Framework rows produce typed edges the same way.
4. Answer: bounded plain text, 40-line cap on lists with a trailing "… and N more".

### Data
Symbol `(id, file, kind, name, qualname, line_start, line_end, signature)`;
Edge `(src, dst, kind, confidence, evidence_file, evidence_line)`;
kinds: `contains imports calls route depends graph_node graph_edge relationship task`.
Framework row: `(framework, language, query_name, edge_kind, target_capture)`.

### Commands (all accept `--repo`, default cwd's toplevel)
`skeleton <path>...` · `callers <symbol> [--depth N] [--min-confidence extracted]` ·
`deps <path|symbol> [--depth N]` · `grep <regex>` (rg hits grouped by enclosing symbol) ·
`pack --files <path>... [--task TEXT]` (≤15 lines: HEAD stamp, entry points, files,
known callers, skeletons, STOP line; drop order skeletons → callers → entry points) ·
`entrypoints` · `install-skill` (copies `skills/wiremap/SKILL.md` to
`~/.claude/skills/wiremap/`) · `cache prune [--days 30]`.
Exit codes: 0 ok · 1 symbol not found / ambiguous (candidates printed) · 2 repo or
parse error (also when > 10 % of files fail to parse).

### Edge cases (decided)
Not a git repo → exit 2. Detached HEAD → stamp `<sha> (detached)`. No commits →
stamp `no-commit`. Per-file parse failure → stderr warning, continue. Dynamic dispatch
(`getattr`, `importlib`, `globals()[`) → one "dynamic dispatch present at file:line"
notice in `deps`. Common names → capped, sorted by confidence then file. Cache
corruption → miss. Two concurrent runs → atomic rename, idempotent.

### SKILL.md (five rules)
1 `callers` before editing a symbol — INFERRED = lead, EXTRACTED = fact, "unresolved"
= grep before assuming none. 2 `skeleton` before reading a whole file. 3 `pack` output
pasted verbatim as the brief's context pack. 4 Reviewers run `callers` on every changed
public symbol. 5 Tool never outranks code: contradiction → STOP, report BLOCKED.

### Roadmap (all in this plan since 2026-09-14 — Phases 7–15 below)
Order shipped: languages (Go, Rust) → cross-artifact edges (SQL, docs) → multi-repo
workspaces → communities + visualisation → PR triage → hook + statusline → LSP resolution
→ LLM summaries → docs/rules. MCP: never.

### Risks
Small published effect size (metrics hook first, compare before mandating); tree-sitter
node-name churn (exact pins + fixture test in CI); name-only method resolution (INFERRED,
LSP later); TS gets generic edges only in v1; cache growth (`cache prune`); adoption
drift (SKILL rules + reviewer checklist only); public hygiene (synthetic fixture only).

## Pre-mortem

Flow: `wiremap <cmd>` → discover → parse/cache → resolve → print. Persisted result: only
cache entries and stdout.

1. **Order & repetition** — two agents run at once and both miss the cache for the same
   file: both parse, both write via temp+rename; last wins with identical content.
   Covered, untested. Interrupted write → partial temp file never renamed. Covered.
2. **Boundaries** — empty repo: `pack` prints stamp + STOP only (2 lines); `callers`
   with zero results prints `no callers found (unresolved: 0)`, never blank. Covered
   by `test_callers_none_is_explicit`. 40-line cap inclusive; line 41+ collapse to
   "… and N more". Covered by `test_pack_fits_15_lines`.
3. **Absence** — symbol not found → exit 1 with "not found"; bare name matching
   several symbols → exit 1 listing candidates (never a silent pick). Covered by
   `test_ambiguous_name_lists_candidates`. Missing HEAD → `no-commit` stamp. Accepted.
4. **Error paths** — one file fails to parse: warning, continue; > 10 % → exit 2.
   Covered, untested (budget).
5. **Concurrency** — see 1.
6. **Contracts** — symbol id is `<module>.<qualname>` (module = path with `/`→`.`,
   no extension); `callers` accepts bare or qualified. `pack` output MUST match the
   agents.md context-pack contract: first line `HEAD <sha> [branch|(detached)]`, last
   line the STOP sentence. Covered by `test_pack_fits_15_lines`.
7. **Existing callers** — none (new repo). The flow's agents.md rule already names the
   pack contents; SKILL.md rule 3 makes `pack` the producer. Covered.
8. **Effects & time** — cache prune by mtime only; no clocks elsewhere. Accepted.
9. **Framework rows** — a wrong tree-sitter query silently produces zero framework
   edges. Covered by `test_framework_edges` on the fixture (Depends, add_node/add_edge,
   relationship, delay) — one assertion per row.
10. **Metrics baseline (No-downgrades)** — `~/.claude.json` per-project keys may lag one
    session behind when `SessionEnd` fires. Accepted: still a per-session series; the
    first run's README note says gaps are missing, never zero.

## Task conventions

Every task: one file (or one named region of one file), 2–5 min of agent work, the
snippet is the shape to type, "Verify" is the check the implementer runs and pastes.
Untouched by default: everything not named in the task. Module map (src layout):

```
src/wiremap/
  __init__.py     __version__
  cli.py          argparse, exit codes, --repo/--stats
  discover.py     toplevel, head_stamp, files
  parse.py        Symbol, RawEdge, language loading, parse_file, cache
  frameworks.py   Rule, RULES
  resolve.py      Edge, Graph, index, _resolve, labels, build
  commands.py     callers, deps, entrypoints, skeleton, grep, pack, install_skill, cache_prune
  queries/python.scm  queries/typescript.scm
skills/wiremap/SKILL.md
tests/conftest.py  tests/test_wiremap.py
```
Shared types (T3d) used everywhere below:
```python
@dataclass(frozen=True)
class Symbol:  id: str; file: str; kind: str; name: str; qualname: str; line_start: int; line_end: int; signature: str
@dataclass(frozen=True)
class RawEdge: src: str; kind: str; target_text: str; line: int; file: str
# id == f"{module}.{qualname}"; module = file path without extension, "/" -> "."
```

```python
class RepoError(Exception): ...
def _git(root, *a) -> str: return subprocess.run(["git","-C",str(root),*a],capture_output=True,text=True,check=True).stdout.strip()
def toplevel(path: Path) -> Path:
    try: return Path(_git(path, "rev-parse", "--show-toplevel"))
    except subprocess.CalledProcessError: raise RepoError(f"not a git repository: {path}")
def head_stamp(root: Path) -> str:
    try: sha = _git(root, "rev-parse", "--short", "HEAD")
    except subprocess.CalledProcessError: return "no-commit"
    branch = _git(root, "branch", "--show-current")
    return f"{sha} {branch or '(detached)'}"
```

```python
from tree_sitter import Language, Parser, Query, QueryCursor
_LANGS = {"python": Language(tree_sitter_python.language()),
```

### T3e — `parse.py`: `parse_file`
```python
def _enclosing(defs: list[tuple[Node, str]], node: Node) -> str | None:   # innermost def whose byte range contains node → qualname
def parse_file(path: Path, root: Path, lang: str) -> tuple[list[Symbol], list[RawEdge]]:
    src = path.read_bytes(); rel = str(path.relative_to(root)); module = rel.rsplit(".", 1)[0].replace("/", ".")
    caps = captures(lang, src)
    defs = []   # (node, qualname) — qualname = ".".join(enclosing chain + name), computed by sorting def.node by start byte and nesting by range containment
    symbols = [Symbol(id=f"{module}.{q}", file=rel, kind=..., name=..., qualname=q, line_start=n.start_point[0]+1, line_end=n.end_point[0]+1, signature=first_line(n)) for n, q in defs]
    edges = [RawEdge(src=f"{module}.{_enclosing(defs, c)}" if _enclosing(defs, c) else module, kind="calls", target_text=callee_text, line=c.start_point[0]+1, file=rel) for c in caps.get("call.node", [])]
    edges += [RawEdge(src=module, kind="imports", target_text=<module or module.name>, line=..., file=rel) for import captures]
    return symbols, edges
```
`kind` is `class` for class nodes, `method` for a def nested in a class, else `function`.
Call nodes whose parent is a `decorator` are skipped (route decorators are framework rows, not calls).
Verify: `parse_file` on fixture `app/api.py` returns the route handler with `kind=="function"` and a `calls` edge with `target_text=="Depends"`.

### T3f — `parse.py`: cache
```python
SCHEMA = 1
def cache_dir(root: Path) -> Path: return Path.home()/".cache"/"wiremap"/hashlib.sha1(str(root).encode()).hexdigest()
def load_or_parse(path, root, lang) -> tuple[list[Symbol], list[RawEdge], bool]:
    src = path.read_bytes(); entry = cache_dir(root)/f"{hashlib.sha1(src).hexdigest()}.json"
    if entry.exists():
        d = json.loads(entry.read_text())
        if d.get("schema") == SCHEMA: return [Symbol(**s) for s in d["symbols"]], [RawEdge(**e) for e in d["edges"]], True
    symbols, edges = parse_file(path, root, lang)
    entry.parent.mkdir(parents=True, exist_ok=True); tmp = entry.with_suffix(".tmp")
    tmp.write_text(json.dumps({"schema": SCHEMA, "symbols": [asdict(s) for s in symbols], "edges": [asdict(e) for e in edges]})); tmp.replace(entry)
    return symbols, edges, False
```

### T5b — `resolve.py`: `_resolve`
```python
def _resolve(raw: RawEdge, module: str, imports: dict[str, str], by_id, by_name, unresolved) -> tuple[str, str] | None:
    t = raw.target_text.split(".")[-1]
    if (cand := f"{module}.{t}") in by_id: return cand, "EXTRACTED"
    if t in imports and imports[t] in by_id: return imports[t], "EXTRACTED"
    ids = by_name.get(t, [])
    if len(ids) == 1: return ids[0], "INFERRED"
    if len(ids) > 1: unresolved[t] = len(ids)
    return None
```
`imports` maps local name → id for `from x import y` / `import x`; `module_of(file)` = path without extension, `/`→`.` (never derived from `raw.src`). Verify: `Depends` from
`fastapi` (not in repo) resolves to `None` without an unresolved entry; `get_db` resolves EXTRACTED.

### T5c — `resolve.py`: labels and `build`
```python
def build(root: Path, stats: bool = False) -> Graph:
    syms, raws, hits = [], [], 0
    for path, lang in files(root):
        s, e, hit = load_or_parse(path, root, lang); syms += s; raws += e; hits += hit
    by_id, by_name = index(syms); edges, unresolved, labels = [], {}, {}   # labels: add_node label -> resolved target id
    for raw in [r for r in raws if r.kind == "graph_node"] + [r for r in raws if r.kind != "graph_node"]:   # nodes first so labels exist for edges
```

### T6a — `commands.py`: `callers`
```python
CAP = 40
def _cap(lines): return lines if len(lines) <= CAP else lines[:CAP] + [f"… and {len(lines)-CAP} more"]
def _find(g, symbol) -> tuple[list[str], int]:      # exact id, else bare-name matches; (ids, exit_code) — >1 → candidates, exit 1
def callers(g: Graph, symbol: str, depth: int = 1, min_conf: str = "INFERRED") -> tuple[str, int]:
    ids, code = _find(g, symbol)
    if code: return "\n".join(["ambiguous, candidates:"] + ids) if ids else f"not found: {symbol}", 1
    seen, frontier, rows = set(), {ids[0]}, []
    for _ in range(depth):
        nxt = set()
        for e in g.edges:
            if e.dst in frontier and e.src != e.dst and e.src not in seen and (min_conf == "INFERRED" or e.confidence == "EXTRACTED"):   # route/task rows are self-loops; entrypoints shows them
                rows.append(f"{e.src}  {e.kind}  {e.confidence}  {e.file}:{e.line}"); seen.add(e.src); nxt.add(e.src)
        frontier = nxt
    rows.sort(key=lambda r: ("INFERRED" in r, r))
    body = _cap(rows) or [f"no callers found"]
    return "\n".join(body + [f"unresolved: {g.unresolved.get(symbol.split('.')[-1], 0)}"]), 0
```

```python
SERVERS = {"python": ["pyright-langserver", "--stdio"], "typescript": ["typescript-language-server", "--stdio"], "tsx": ["typescript-language-server", "--stdio"]}
class Lsp:
    def __init__(self, root: Path, lang: str):
        self.root, self.n, self.opened = root, 0, set()
        self.p = subprocess.Popen(SERVERS[lang], cwd=root, stdin=subprocess.PIPE, stdout=subprocess.PIPE, stderr=subprocess.DEVNULL)
        self.call("initialize", {"processId": None, "rootUri": root.as_uri(), "capabilities": {}}); self.notify("initialized", {})
    def _send(self, msg):
        b = json.dumps(msg).encode(); self.p.stdin.write(f"Content-Length: {len(b)}\r\n\r\n".encode() + b); self.p.stdin.flush()
    def notify(self, method, params): self._send({"jsonrpc": "2.0", "method": method, "params": params})
    def call(self, method, params):
        self.n += 1; self._send({"jsonrpc": "2.0", "id": self.n, "method": method, "params": params})
        while True:
            hdr = self.p.stdout.readline()
            if not hdr: raise RuntimeError("lsp exited")
            if hdr.lower().startswith(b"content-length:"):
                n = int(hdr.split(b":")[1]); self.p.stdout.readline(); msg = json.loads(self.p.stdout.read(n))
                if msg.get("id") == self.n: return msg.get("result")
    def definition(self, rel: str, line: int, col: int) -> tuple[str, int] | None:     # 1-based in, (rel_file, 1-based line) out
        uri = (self.root / rel).as_uri()
        if rel not in self.opened:
            self.opened.add(rel); self.notify("textDocument/didOpen", {"textDocument": {"uri": uri, "languageId": "python", "version": 1, "text": (self.root / rel).read_text()}})
        r = self.call("textDocument/definition", {"textDocument": {"uri": uri}, "position": {"line": line - 1, "character": col}})
        if not r: return None
        loc = r[0] if isinstance(r, list) else r
        path = Path(urllib.parse.unquote(urllib.parse.urlparse(loc.get("uri") or loc["targetUri"]).path))
        try: return str(path.relative_to(self.root)), (loc.get("range") or loc["targetRange"])["start"]["line"] + 1
        except ValueError: return None
    def close(self): self.p.kill()
```
